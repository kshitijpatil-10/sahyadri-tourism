
# 🏔️ Sahyadri Tourism Website

A tourism website inspired by the beautiful Sahyadri mountain ranges of Maharashtra, India. This project was created as part of my frontend development learning journey while practising HTML and CSS.

## 📌 About the Project

Sahyadri Tourism is a beginner-level frontend practice project focused on building a tourism-themed website using HTML and CSS.

The main goal was to apply my learnings, practise webpage layouts, and improve my frontend development fundamentals through hands-on experience.

## ✨ Features

- Tourism-themed website design
- Structured webpages using HTML5
- Styling and layouts using CSS3
- Images and visual elements
- Hands-on frontend development practice

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/kshitijpatil-10/sahyadri-tourism.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser.

4. Alternatively, use the Live Server extension in VS Code to run the website locally.
